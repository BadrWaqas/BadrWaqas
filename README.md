# Badr Waqas

Data Science student at NCI Dublin, originally from the UAE. I learn by building, so most of what's here started as a question about the city I moved to.

I work with real data rather than curated datasets: live APIs, government records, and whatever needs cleaning before it's usable. Everything here runs, and the READMEs document the limitations as well as the results.

**[dublin-bikes-analysis](https://github.com/BadrWaqas/dublin-bikes-analysis)** — an automated pipeline polling the Dublin Bikes API every 5 minutes, building a time-series dataset from a feed that only reports the current moment. Cleaned, analysed, and served through a Streamlit dashboard.

**[irish-housing-ml](https://github.com/BadrWaqas/irish-housing-ml)** — 797,000 Irish property sales loaded into SQLite, explored with SQL, and modelled with Linear Regression and Random Forest. The models explain around 43% of price variation, and the write-up covers why the public dataset can't account for the rest.

**[chess-self-analysis](https://github.com/BadrWaqas/chess-self-analysis)** — four years of my own Chess.com games analysed with Stockfish, covering rating progression, opening tendencies, and where in a game my accuracy drops.

Outside data, I made **[Sandscape](https://github.com/BadrWaqas/sandscape-app)**, a desktop app that teaches Python through a box of glowing, musical sand. Free for Windows.
